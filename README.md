# Xeni Brand Films

Self-contained, embeddable HTML brand films for Xeni. Each film autoplays, loops, and works straight from a URL or an `<iframe>` — no build step and no external dependencies (fonts and imagery are inlined).

Served via GitHub Pages: **https://xeni-repos.github.io/brand-films/**
